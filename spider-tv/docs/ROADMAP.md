- [ ] اقتران البلوتوث (BlueZ agent للريموت والسماعات)
- [ ] mpv كمشغّل أصلي (كل الصيغ، تسريع العتاد، ترجمات) مع نفس واجهة التحكم
- [ ] ريموت HDMI-CEC (`cec-client` أو `libcec` يحوّل الأزرار إلى أحداث لوحة مفاتيح)

- [ ] اختبار AirPlay على الجهاز، وتقييم حلول أندرويد
- [ ] Spotify Connect (librespot)

- [ ] إخفاء سطح المكتب والمؤشر ورسائل الإقلاع (شاشة إقلاع بشعار SPIDER)
