# SPIDER TV OS

واجهة تلفزيون ذكي (TV Launcher + System Shell) لجهاز مستقل يتوصل بشاشة SHARP عبر HDMI.
هوية بصرية أصلية مستوحاة من عالم Spider-Man، مصممة للاستخدام من مسافة بعيدة بالريموت.

> هذه **المرحلة 1: نموذج أولي يشتغل**. تشغيله الآن على الماك، والانتقال لجهاز مستقل يكون بعد ما نعتمد التصميم.

## التشغيل على الماك

المتطلبات: Node.js 20.19 أو أحدث (يُفضّل 22) (`brew install node`)، و Google Chrome (لفتح تطبيقات البث).

```bash
cd spider-tv
npm install

# وضع التطوير (تحديث تلقائي عند تعديل الكود)
npm run dev          # ثم افتح http://localhost:5173

# وضع التلفزيون: ملء الشاشة في نافذة Chrome مستقلة، مثل ما يشتغل على الجهاز
npm run tv           # للخروج: ⌘Q
npm run tv:window    # نفس الشي لكن في نافذة 1920×1080 بدل ملء الشاشة
```

### اختبار سريع

1. حط أي فيديو `mp4` أو `webm` في مجلد `~/Movies`.
2. شغّل `npm run dev` وافتح `http://localhost:5173`.
3. تنقّل بالأسهم فقط (بدون ماوس). ستلاحظ:
   - الخلفية والعنوان يتغيرون حسب العنصر المحدد.
   - الفيديو يظهر في «مكتبتك»، وبعد ما تشغّله وتطلع منه يظهر في «تابع المشاهدة».
   - الإعدادات ← الثيمات: غيّر الثيم وشوف الواجهة كلها تتغير.
   - الإعدادات ← اللغة: English يقلب الواجهة كاملة إلى LTR.
   - الإعدادات ← الصوت: يغيّر صوت الماك الحقيقي.
4. اختبارات الكود: `npm test` و `npm run typecheck`.

### التحكم

| الزر | لوحة المفاتيح (تطوير) | الريموت |
|---|---|---|
| تنقّل | الأسهم | D-pad |
| اختيار | Enter | OK |
| رجوع | Esc أو Backspace | Back |
| بحث | `/` | Search |
| الصوت | `+` و `-` | Volume +/- |
| تشغيل/إيقاف | Enter أو Space داخل المشغّل | Play/Pause |

أزرار الريموت تصل كأحداث لوحة مفاتيح، ومعها أكواد ريموتات التلفزيونات المعروفة (webOS/Tizen). ربط ريموت HDMI-CEC فعليًا يكون في المرحلة 2.

## ما تم تنفيذه فعليًا

| الميزة | الحالة | ملاحظات |
|---|---|---|
| الشاشة الرئيسية | تعمل | شعار، ساعة وتاريخ، حالة الإنترنت (فحص HTTP حقيقي)، المفضلة، تابع المشاهدة (من بيانات حقيقية فقط)، تطبيقاتك، مكتبتك، خلفيات سينمائية متغيرة |
| نظام التنقل بالريموت | يعمل | تنقل مكاني (Spatial) بالأسهم، يتذكر آخر عنصر في كل صف، طبقات للنوافذ، زر رجوع بسجل، يدعم RTL |
| الثيمات الأربعة | تعمل | Classic، Miles، Symbiote، 2099. تغيّر الألوان والخلفيات والأنماط والتأثيرات |
| العربية والإنجليزية + RTL | تعمل | العربية افتراضية |
| صفحة التطبيقات | تعمل | لكل تطبيق حالة دعم صريحة، إضافة/إزالة من المفضلة |
| فتح تطبيقات البث | تعمل* | تنفتح في نافذة Chrome مستقلة بملء الشاشة. *Netflix وغيرها مقيدة بـ DRM، شوف [docs/APPS_AND_DRM.md](docs/APPS_AND_DRM.md) |
| مشغّل الفيديو المحلي | يعمل | تقديم/ترجيع، حفظ مكان التوقف، رسالة واضحة إذا الصيغة غير مدعومة |
| مدير الملفات | يعمل | قراءة فقط، ومحصور في مجلدات محددة (حماية من الخروج من المجلد) |
| البحث | يعمل | لوحة مفاتيح على الشاشة (عربي/إنجليزي) + لوحة المفاتيح العادية |
| الإعدادات | جزئي | التفاصيل تحت |
| مشاركة الشاشة AirPlay | يعمل إذا UxPlay مثبّت | التطبيق يشغّل ويوقف UxPlay. التفاصيل في [docs/SCREEN_MIRRORING.md](docs/SCREEN_MIRRORING.md) |

### الإعدادات: الحقيقي وغير المنفّذ

| القسم | الحقيقي الآن | غير منفّذ (ظاهر كـ «مخطط له» مع السبب) |
|---|---|---|
| الشبكة | الاتصال بالإنترنت، زمن الاستجابة، الواجهات وعناوين IP، اسم الشبكة، قائمة الشبكات على لينكس | الاتصال بشبكة Wi-Fi من التلفزيون (المرحلة 2) |
| البلوتوث | حالة المحوّل والأجهزة المقترنة (قراءة) | الاقتران (المرحلة 2) |
| الشاشة | الدقة، نسبة البكسل، معدل التحديث (مقاس)، هوامش الشاشة للتلفزيونات القديمة، تقليل الحركة، ساعة 24 | تغيير وضع HDMI (المرحلة 3) |
| الصوت | مستوى الصوت وكتم حقيقي (ماك: osascript، لينكس: PipeWire/ALSA) | — |
| التخزين | الأقراص والمساحة، مجلدات الوسائط | — |
| التطبيقات | المفضلة وحالة الدعم | — |
| الثيمات واللغة | كاملة | — |
| مشاركة الشاشة | AirPlay عبر UxPlay | أندرويد (المرحلة 2، قيد التقييم) |
| معلومات النظام | الجهاز، النظام، المعالج، الذاكرة، مدة التشغيل، الإصدارات | — |
| التحديثات | الإصدار الحالي | التحديث التلقائي (المرحلة 4) |

ما في زر «يتظاهر» إنه يشتغل: أي ميزة غير منفّذة يمكن الوصول لها بالريموت، وتعرض شارة المرحلة وسبب عدم توفرها.

## هيكل المشروع

```
spider-tv/
├── agent/              خدمة النظام (Node.js بدون مكتبات خارجية). الوحيدة اللي تلمس نظام التشغيل
│   ├── server.js       REST API على 127.0.0.1:7766 + تقديم الواجهة المبنية
│   ├── lib/            الشبكة، الصوت، البلوتوث، الوسائط، الملفات، تشغيل التطبيقات، AirPlay
│   └── test/           اختبارات المحللات والحماية
├── shared/catalog.json قائمة التطبيقات (مصدر واحد للواجهة والخدمة)
├── ui/                 الواجهة (React + TypeScript + Vite)
│   └── src/
│       ├── core/nav/   محرك التنقل بالريموت (spatial navigation)
│       ├── core/i18n/  العربية والإنجليزية
│       ├── core/       الثيمات، الحالة، الاتصال بالخدمة، التوجيه
│       ├── components/ الأيقونات (SVG أصلية)، الشعار، الخلفيات الإجرائية، البطاقات…
│       ├── screens/    الرئيسية، التطبيقات، الوسائط، الملفات، المشغّل، البحث، الإعدادات
│       └── styles/     الألوان والثيمات والتصميم
├── scripts/            dev و tv
└── docs/               المعمارية، التطبيقات وDRM، مشاركة الشاشة، خطة المراحل
```

إعدادات اختيارية بمتغيرات البيئة: `SPIDER_MEDIA_DIRS` (مجلدات الفيديو، مفصولة بـ `:`)، `SPIDER_FILE_ROOTS`، `SPIDER_PORT`، `SPIDER_BROWSER`، `SPIDER_AIRPLAY_NAME`.
البيانات (التفضيلات ومكان التوقف) تنحفظ في `~/.spider-tv/`.

## الأصول البصرية

كل الرسومات أصلية ومولّدة بالكود: الشعار، الأيقونات، أنماط الشبكة، الهالفتون، العروق (Symbiote)، الشبكة السداسية (2099).
ما في صور أو شعارات محمية. بطاقات التطبيقات تعرض اسم الخدمة بلونها فقط؛ إضافة الشعارات الرسمية تحتاج الالتزام بإرشادات كل علامة تجارية.
الخط: Readex Pro (رخصة SIL Open Font) مضمّن محليًا عشان الواجهة تشتغل بدون إنترنت.
